# 群聊 PC 拟真测试（2026-10-21）

> 目的：在移植 Android 之前，用**与手机同一个 Qwen3.5-4B、同一份人设系统提示**，在电脑上先跑 2–3 个 AI + 用户的群聊，看机制是否成立、质量是否值得移植。
> 结论：**机制成立，拟真度还不过关；先不要上手机。**

## 一、测试装置

- 脚本：`scripts\group-sim.py`（新增）
- 模型：`models\candidates\Qwen3.5-4B-Q4_K_M.gguf`（与手机默认模型同一份）
- 后端：PC Vulkan `llama-server`，4096 上下文
- 人设提示：`scripts\dump-prompts.ps1` 导出的 14 份 `Personas.promptFor`（与 App 完全一致）
- 结构：5 个群 × 3 轮
  - 用户发一条广播 → 程序抽 1–2 个 AI 回应；
  - 用户 `@` 指定 AI → 该 AI 必回；
  - 另一个 AI 读到“用户 + 被 @ 者”的对话后反应一句。
- 成员：2–3 个 AI + 用户（用户是参与者，不是旁观者）。
- 输出：`run\eval\group-sim-q35_4b.json` / `.md`

## 二、结果

| 指标 | 第一轮（无声音提示） | 第二轮（加声音提示） |
|---|---|---|
| 场次 / AI 回复 | 5 场 / 19 条 | 5 场 / 19 条 |
| 用时 | 50s | 50s |
| 空回复 | 0% | 0% |
| `@` 必回 | 5 / 5 | 5 / 5 |
| 自己的口吻标记 | 37% | **53%** |
| 串味（非点名） | 11%（含点名误报） | 5%（唯一一条是点名“小满”，按非名字词表为 0） |
| >40 字 | 5% | 5% |
| 虚假动作声明 | 5% | 0% |
| 出戏（AI/模型） | 0% | 0% |
| 复读循环 | 0% | 0% |
| 与本场已有回复重复 | 0% | 0% |
| 平均字数 | 26 | 25 |

## 三、能确认成立的部分

1. **用户 @ 必回**：5/5，被 @ 的 AI 都给出回应。
2. **其他 AI 能读到**“用户 + 被 @ 者”的对话，并据此反应。
3. **广播投递 + 抽样回应**成立：不是每个 AI 都生成，但每个都收到；沉默是允许的。
4. **2–3 轮**能跑完，PC 上 19 条回复约 50 秒；手机上会慢 3–6 倍，但结构可行。
5. **加一句“声音提示”后，口吻标记从 37% 升到 53%**，说明系统提示对群聊有效，但还不够。

## 四、还不过关的部分

| 问题 | 例子 | 结论 |
|---|---|---|
| **像嘉宾答题，不像群聊** | 三个人都围绕“稳定 vs 热爱”各给一句结论 | 需要“只从自己的处境出发、反驳/追问上一位”的群聊导演规则 |
| **观点/句式回声** | friends 场：阿冷“当场说破！憋着才是真的不舒服”，陈野“当场说破！憋着才是真憋屈” | 需要“不要重复上一位的观点/句式”的硬约束 + 上下文去重 |
| **人设仍偏模板** | 傅沉“稳定是枷锁，热爱才是方向。但我的决定，只由你来做。”——后半句不像他 | 需要 Persona Bible v2 的逐人声音 DNA，而不是一句提示 |
| **动作注释失控** | 小咪“（蹭蹭屏幕）”无视“本轮不写旁白”的指令 | 动作需要 `ActionNoteGuard` + 明确动作库，不能只靠提示词 |
| **个别人设过短/过平** | 零“藏起来，然后睡。”“睡醒再说。” | 零可以短，但需要“短而具体”，不能像自动回复 |
| **虚构细节** | 阿壹“新开的宠物店” | 朋友圈/群聊里要区分“虚构生活”与“编造用户事实”；需要 `MomentGuard` 类规则 |

## 五、结论与门禁

- **机制可行，拟真度未达标**：现在移植到手机，只会得到一个“三个人轮流答题”的群，不是“他们真的在聊”。
- 在以下条件满足前，**不部署群聊到手机**：
  1. 《人设圣经 v2》完成，14 人声音/动作/小传重写；
  2. 群聊导演规则加入“反驳/追问/不重复/按关系站位”；
  3. PC 复跑：口吻标记 ≥70%、非点名串味 ≤2%、观点回声 ≤10%、@ 100%；
  4. 人工读 5 场样本，认为“像群聊”而不是“像访谈”。
- 下一步同样用 PC 先测：**多轮单聊、会话摘要、未来话题编排、朋友圈、主动开场**；通过后再动 Android。

## 六、复现

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File minicpm-v4.7\scripts\dump-prompts.ps1
python -u minicpm-v4.7\scripts\group-sim.py --all --samples 1 --seed 11
```

结果：`run\eval\group-sim-q35_4b.md`、`run\eval\group-sim-q35_4b.json`。
